# Supervisor Report: AI Model Training and Output Evaluation

## Project Title
AI Model Training and Comparison for Tourism Recommendation

## Report Purpose
This report explains:

1. how the project data is prepared,
2. how each model is trained,
3. what outputs are generated,
4. which model performs best, and
5. which result is the most reliable for academic presentation.

## 1. Project Overview
This project uses a tourism dataset to train and compare multiple machine learning models for a binary recommendation task. The main target variable is `recommendation_label`, where the models predict whether a tourism-related item should be recommended.

The project also includes one LSTM-based forecasting model. However, that LSTM predicts monthly demand values, not recommendation labels. Because of that, the LSTM results are not directly comparable with the classification models.

## 2. Dataset and Feature Preparation
The dataset used in this project is:

- `data/tourism_ai_master_dataset_v2_full.csv`

The preprocessing script is:

- `src/prepare_data.py`

### Preprocessing steps
The data preparation process performs the following steps:

1. Loads the tourism dataset.
2. Selects `recommendation_label` as the target column.
3. Uses `ml_text_features` as the main text feature.
4. Uses the following numeric features when available:
   - `rooms`
   - `latitude`
   - `longitude`
   - `has_coordinates`
   - `total_foreign_arrivals_month`
   - `month_share_of_known_year_arrivals`
   - `district_total_entities`
   - `selected_site_count_in_district`
5. Cleans numeric columns by converting invalid values and replacing missing values with `0`.
6. Splits the data into training and testing sets using:
   - `test_size=0.2`
   - `random_state=42`
   - `stratify=y`
7. Converts text into TF-IDF features using:
   - maximum `5000` features
   - English stop word removal
   - unigram and bigram features
8. Scales numeric features using `StandardScaler`.
9. Combines text and numeric features into the final training and testing matrices.

## 8. Important Technical Observations
There are two important points that should be mentioned honestly in a university report.

### Observation 1: LSTM is not directly comparable
The LSTM model predicts monthly tourism demand, while the other models predict recommendation labels. Since the target and evaluation metrics are different, the LSTM should be discussed separately and should not be ranked together with the classifiers.

### Observation 2: The hybrid models are not true integrated hybrids
The scripts:

- `src/train_svm_lstm.py`
- `src/train_knn_lstm.py`

use a fixed placeholder:

- `lstm_demand_score = 0.5`

This means the LSTM output is not actually being generated dynamically and combined from real prediction values. As a result:

- `SVM + LSTM` has exactly the same metrics as `SVM`
- `KNN + LSTM` has exactly the same metrics as `KNN`

Therefore, the current hybrid outputs should be described as **placeholder hybrid experiments**, not as fully validated hybrid models.
